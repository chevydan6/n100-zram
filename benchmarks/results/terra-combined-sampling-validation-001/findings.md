# Combined sampling candidates: validation complete

This additive userspace experiment combines the existing 16- and 64-word sampling gates with the bounded direct-block, grouped-scanner GHY1 parent. It reuses the same encoder and decoder objects as the tested parent, and changes encoder selection only; GHY1 frame decoding remains unchanged. The build commands, exact compiler flags, source and binary hashes are in `general-validation.json`. These binaries are prototypes, not stock ZRAM or a promoted compressor.

The generic normal and ASan/UBSan suites passed both candidates, but their generic library names did not trigger sampling-specific boundary tests. The separate boundary pass uses names that activate the sampling, block-selection and scanner-pipeline fixtures. Both normal passes succeeded: each exercised 312 sampling boundaries, 72 block-selection pages, 390 scanner-pipeline pages, guarded buffers, malformed data, four-thread round trips and independent decoding. Both sanitized boundary passes also succeeded with the same boundary counts; see `boundaries.json` and the logs.

The matched harness passed normal and sanitizer correctness checks for 36 corpora; their hashes match the earlier corpus. No timing or energy result is claimed from its short smoke run. Earlier hypothetical probes demonstrate a 29.2% compressed-size regression in adversarial sample64-sparse-miss, while earlier sampling builds used a different parent encoder and do not establish the current combination's performance. Matched measurements must retain that case and compare with the parent and LZ4 under the same physical conditions. Kernel SIMD, native ZRAM, application responsiveness and package energy remain unmeasured for these candidates.
