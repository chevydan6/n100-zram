# Physical test kernel preparation

At the user's request, a separate `7.2.11-n100-gzram` kernel, its built modules, and a host-specific initramfs were staged under `/boot` and `/lib/modules`, with an `Experimental N100 GZRAM` GRUB/BLS entry. The existing `7.2.11-200.fc44.x86_64` kernel remains the saved default. No existing kernel or initramfs was overwritten. Secure Boot was disabled at inspection. The initramfs contains the laptop's eMMC controller and MMC block modules and the built ZRAM module; installed image, initramfs and module hashes matched their staged copies. Dracut emitted a `realpath` warning for the not-yet-installed module directory during generation; its retained log and `lsinitrd` inspection show the staged modules were included.

The experimental kernel had previously passed isolated KVM boot and ZRAM round-trip checks, but actual Lenovo graphics, input, Wi-Fi, audio, storage behavior, recovery and performance remain unverified. The user's manual power-button recovery check worked under normal conditions. The existing GRUB configuration says it clears a one-time `next_entry` and otherwise uses the saved entry; actual alternate-entry fallback after a failure has not been demonstrated. No experimental physical boot or one-time selection is claimed by this record. No experimental compressor has been promoted to the stock ZRAM configuration.
